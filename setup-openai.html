🤖 Setup OpenAI API Key

Enable ChatGPT-powered responses for your Constitution Tutor

📝 Step 1: Get Your API Key

Visit OpenAI's platform and create an API key:

Get OpenAI API Key →
  • Sign up or log in to your OpenAI account
  • Click "Create new secret key"
  • Copy the key immediately (you won't see it again!)

⚙️ Step 2: Add Key to .env File

Open the file: server\.env

Replace the placeholder with your actual API key:

MONGO_URI=mongodb+srv://indianConstitution:...

OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxx

🔄 Step 3: Restart the Server

Open PowerShell/Terminal in the server folder and run:

node server.js

You should see: "Connected to MongoDB Atlas"

✅ Step 4: Test the Chatbot

Go to your dashboard and click "Ask AI"

Open Dashboard →

Try asking: "What are Fundamental Rights?"

⚠️ Important: Your .env file is private and should never be shared or committed to Git. It contains sensitive credentials!
