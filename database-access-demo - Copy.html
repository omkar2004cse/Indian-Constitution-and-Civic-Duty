JavaScript Code Examples

1. Get Article by Number:

const article = constitutionManager.getArticleByNumber(21);
console.log(article.id);
console.log(article.description);

2. Search Articles:

const results = constitutionManager.searchArticles('fundamental rights');
console.log(results.length, 'articles found');

3. Get All Articles:

const all = constitutionManager.allArticles;
console.log('Total articles:', all.length);

4. Filter Articles:

const filtered = constitutionManager.allArticles.filter(article => 
    article.description.includes('Parliament')
);
console.log(filtered);
